# Mimari Karar Kayıtları (ADR)

Bu dizin, geri dönüşü maliyetli veya projeyi uzun süre etkileyen teknik kararları saklar.

## Kurallar

1. Yeni kayıt `NNNN-kisa-karar-adi.md` adıyla oluşturulur.
2. Durum değerleri: `Önerildi`, `Kabul edildi`, `Reddedildi`, `Yerine geçti`, `Kullanımdan kaldırıldı`.
3. Karar bağlamı, değerlendirilen seçenekler, gerekçe, olumlu/olumsuz sonuçlar ve geri alma yaklaşımı yazılır.
4. Kabul edilmiş kayıt silinmez veya sonucu değiştirecek biçimde yeniden yazılmaz. Değişiklik için yeni ADR açılır.
5. İlgili PR, issue, risk ve eski/yeni ADR bağlantıları eklenir.

Yeni kayıt için [şablonu](0000-template.md) kopyalayın.
